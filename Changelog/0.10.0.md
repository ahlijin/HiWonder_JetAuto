# Changelog / 更新日志

## 0.10.0 (2026-08-04)

### 新增
- **全向碰撞检测**（odom_publisher_node.py）
  - `scan_callback` 三扇区距离：前方（π±30°）/ 左侧（90°±30°）/ 右侧（270°±30°）
  - 旋转时按转向侧检测：左转（az>0）查左侧、右转（az<0）查右侧
  - 0.15m 停转 / 0.30m 减速（与前进碰撞同阈值逻辑），仅限转向侧，另一侧不误伤
  - 参数 `safety_side_angle`（默认 30°，左右检测扇区半角）
- **旋转堵转检测**（麦轮被卡/打滑）
  - 订阅 IMU（`/ros_robot_controller/imu_raw`），记录角速度 z
  - 旋转指令下 IMU 角速度持续 < `stall_angular_threshold`(0.08 rad/s) 达 `stall_detect_time`(1.0s) → 判堵转
  - 动作：立即停车 + 蜂鸣提示（BuzzerState 500Hz×2）
  - 20Hz 轮询（cal_odom_fun 循环内），无旋转指令时不检测

### 变更
- `app_cmd_vel_callback` angular 限幅 0.5 → 0.6（配合 Jetson 侧 rotate_gain=0.6，唤醒整车旋转速度加倍）
